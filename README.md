# Supafilm Remaster — versions / releases

## Français — À quoi sert ce dépôt ?

Ce dépôt publie les installateurs et mises à jour de Supafilm Remaster. La release `v1.1.0` fournit un installateur Windows et décrit un outil d’upscaling vidéo 4K par glisser-déposer, avec des profils « Film réel » et « Anime ».

### Pourquoi l’utiliser ?

Il centralise les versions téléchargeables et les informations nécessaires pour mettre à jour l’application. Cela aide à retrouver le bon installateur et à consulter les prérequis avant de l’exécuter.

### Exemple d’utilisation

1. Ouvrir l’onglet [Releases](https://github.com/JirA44/supafilm-releases/releases).
2. Lire les notes de version et vérifier les prérequis.
3. Télécharger l’installateur Windows de la version voulue.
4. Avant de lancer l’upscaling, vérifier que FFmpeg est dans le PATH et que Python, PyTorch et un GPU NVIDIA sont disponibles, comme indiqué dans la release.

L’installateur publié est volumineux. Vérifier la version, la source et les besoins matériels avant de le télécharger.

## English — What is this repository for?

This repository publishes installers and updates for Supafilm Remaster. Release `v1.1.0` provides a Windows installer and describes a 4K video upscaling workflow using drag and drop, with “Live Action” and “Anime” profiles.

### Why use it?

It provides one place to find downloadable versions, release notes and prerequisites before installing or updating the application.

### Example

1. Open the [Releases](https://github.com/JirA44/supafilm-releases/releases) page.
2. Read the release notes and check the requirements.
3. Download the installer for the version you want.
4. Before upscaling, check that FFmpeg is on PATH and that Python, PyTorch and an NVIDIA GPU are available, as stated in the release notes.

The published installer is large. Check the version, source and hardware requirements before downloading it.
